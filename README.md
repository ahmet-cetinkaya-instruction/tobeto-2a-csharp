# Tobeto 2.A - C# Backend Training

This repository is a snapshot created for documentation and knowledge-sharing purposes, capturing the content of a technical training delivered for developers learning C# and .NET for backend applications.

## Main Covered Topics

- **C# and .NET Fundamentals**: Core language features and the .NET ecosystem.
- **Layered Architecture**: Separation of concerns into Business, DataAccess, Entities, Core, and Presentation (WebAPI/ConsoleUI) layers for building maintainable applications.
- **Data Access with Entity Framework Core**: Object-Relational Mapping (ORM) for database interactions, including migrations.
- **Design Patterns**: Implementation of the Repository Pattern and Dependency Injection for modular and testable code.
- **Cross-Cutting Concerns**: Handling validation (using FluentValidation), robust exception management, and enforcing business rules.
- **API Development**: Building RESTful APIs using ASP.NET Core WebAPI.
- **Practical Example**: A "Rent-a-Car" application demonstrating full CRUD (Create, Read, Update, Delete) operations for entities such as Brands and Models.
- **Technologies Used**: .NET, C#, ASP.NET Core WebAPI, Entity Framework Core, FluentValidation, AutoMapper.

> Note: This repository is not intended for ongoing development; it is an archive of a specific training program and is provided for reference and knowledge sharing.
